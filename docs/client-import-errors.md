# Import errors and fixes

This reference covers the application's current explicit validation messages for
project CSVs, the supported XLSX/ROT grave files and photographs. `{row}` is a
file row number; `{value}` is the ID, level, field or other value included in the
actual message. A `Row {row}:` or `Could not import grave outline:` prefix may
wrap one of the validation messages below.

Work on a copy of the file and preserve the original measured survey. A failed
import is a reason to correct the format/reference, not to invent coordinates.

## Project CSV

| Message | Cause | Fix |
| --- | --- | --- |
| Row {row} has invalid coordinates | A coordinate contains non-numeric or non-finite text. | Use numeric metre values; leave unrecorded axes blank. Check both normal and inferior columns. |
| Row {row} has an unknown vertical reference: {value} | The saved convention is unrecognised. | Use height or rl in the vertical_reference label; keep the datum convention recorded for the dataset. |
| Row {row} needs the grave floor RL in the z column | The RL reference has no finite floor value. | Supply the measured grave-floor RL in z; zero is allowed, blank is not. |
| Missing CSV columns: {value} | The header is missing required fields. | Copy the complete nine-column header from the guide; check delimiter and spelling. |
| CSV file is missing the application identity row | The identity row is missing, misplaced or duplicated. | Keep exactly one application row immediately after the header, with label 3d_skeleton_plotter. |
| CSV file must start with individual_id "application" and label "3d_skeleton_plotter" | The first data row is not the required identity. | Put application,,,,,,,,3d_skeleton_plotter immediately after the header. |
| Row {row} has no individual_id | A data row has no record owner. | Fill the individual ID or reserved record ID; remove accidental empty/misaligned rows. |
| Row {row} repeats the application identity row | The identity row is missing, misplaced or duplicated. | Keep exactly one application row immediately after the header, with label 3d_skeleton_plotter. |
| Row {row} repeats the image overlay | More than one photograph row is present. | Keep one image_overlay record; replace photographs through the app. |
| Duplicate saved camera view | More than one camera record is present. | Keep one valid project_view record, preferably generated by Save. |
| Invalid or duplicate grave ID | A named grave has a blank or repeated ID. | Give each grave a unique ID and keep its references consistent. |
| Invalid grave details | The grave JSON has invalid name, colour or metadata types. | Use a nonblank name, a six-digit hex colour and string notes/relationship IDs; edit and save through the app. |
| Row {row} has invalid contour reference JSON | The reference label cannot be parsed as JSON. | Restore properly CSV-escaped reference JSON from an app-generated file. |
| Row {row} has invalid grave ID | The reference grave ID is blank or not a string. | Use the existing named grave ID as a nonblank string. |
| Row {row} has an invalid or duplicate contour reference | The level is invalid or its reference is repeated. | Use top or bottom and only one reference for each grave/level. |
| Row {row} has invalid grave outline level: {value} | The contour level is unsupported. | Use top or bottom in joint_id; base is represented by bottom in CSV. |
| Row {row} needs complete grave outline coordinates | A perimeter point is incomplete. | Supply all x/y/z values for each outline vertex; do not invent missing survey coordinates. |
| Row {row} repeats grave membership | An individual has multiple assignment records. | Keep one joint_id=grave record for that individual. |
| Row {row} has unknown joint_id: {value} | The anatomical ID is unsupported. | Use the exact IDs in the guide; do not use the display label as the ID. |
| Row {row} gives {value} a different label | Rows for one individual contain conflicting labels. | Use the same nonblank label for that ID, or label only one coordinate row. |
| Row {row} repeats {value} for {value} | The same joint occurs more than once for an individual. | Keep one row per individual/joint; use inferior columns for split positions. |
| Unknown grave ID: {value} | A contour points to a grave that is not defined. | Add the matching grave metadata record or correct the reference ID. |
| Named graves cannot mix with unassigned legacy contour rows | Named and unassigned legacy contour rows are mixed. | Assign contour rows consistently to named graves, or use a single legacy pair. |
| {value} reference has no contour | Metadata exists without its perimeter. | Restore the matching top/bottom points or remove the orphan reference. |
| Invalid cuts-into relation for {value} | A cutting relationship points to itself or a missing grave. | Choose another existing grave, or None recorded. |
| Grave cutting relationships contain a cycle | The cutting relationships loop back to an earlier grave. | Review the recorded interpretation and remove the cyclic relationship. |
| Individual refers to unknown grave: {value} | An individual is assigned to an undefined grave. | Correct the assignment to an existing ID or clear it. |

| The grave-cut section is empty | There are no perimeter points in the ROT section. | Obtain the measured grave-cut perimeter; an empty section cannot define a contour. |

## Contour points and reference

| Message | Cause | Fix |
| --- | --- | --- |
| {value} must contain points | Contour data is not an array of points. | Restore the point records using a valid project or supported survey file. |
| {value} point {value} needs three finite coordinates | A contour point is missing an axis or has invalid text. | Enter complete numeric x/y/z for that point. |
| {value} needs at least three distinct perimeter vertices | The contour has fewer than three distinct XY points. | Obtain at least three measured perimeter vertices; a repeated closing point does not count again. |
| Choose height above floor or RL distance down | The contour convention was not selected. | Select height above floor or RL distance down explicitly. |
| {value} must be a finite number | A floor RL, offset or height input is blank/invalid. | Enter a finite numeric value for the named field; use the measured floor RL and explicit offsets. |

## Photograph bytes and saved image

| Message | Cause | Fix |
| --- | --- | --- |
| Choose an image no larger than 10 MB | The image is empty or exceeds the file-size bound. | Choose a valid nonempty PNG/JPEG under 10 MiB; reduce image size before importing. |
| Choose a valid PNG or JPEG photograph | The image header is invalid or the format unsupported. | Re-export as PNG/JPEG; changing the extension alone does not convert the image. |
| Image must be at most 8192 pixels per side and 16 megapixels; resize it before importing | Pixel dimensions exceed the allowed limit. | Resize to at most 8192 pixels per side and below the 16-megapixel bound, then retry. |
| Image source must be a filename | The saved source is missing or contains a directory path. | Use the original filename only; reload and save the photograph through the app. |
| Image exceeds 10 MB | The embedded data exceeds the size bound or is invalid. | Reload a valid smaller image and save a new project rather than editing base64 by hand. |
| Saved image must contain embedded PNG or JPEG data | The embedded image data URL/base64 is malformed. | Reload the original PNG/JPEG and save through the app, or restore a known-good project. |
| Saved image data is invalid | The embedded base64 cannot be decoded. | Restore a known-good file or reload the original photograph. |
| Image dimensions or format do not match its embedded data | Saved dimensions/MIME differ from the embedded bytes. | Reload and save the image through the app so bytes and metadata agree. |

## Photograph alignment

| Message | Cause | Fix |
| --- | --- | --- |
| Image corner coordinates must be finite numbers | A corner is not a finite numeric pair. | Enter x/y numbers for all three corners; do not edit numeric JSON fields as strings. |
| Corners must run bottom-left, bottom-right, top-left, with a positive area | Corners are coincident, collinear or ordered with negative area. | Use bottom-left, bottom-right, top-left in that order with a nonzero positive-area extent. |
| Image height above floor must be a finite number | A floor RL, offset or height input is blank/invalid. | Enter a finite numeric value for the named field; use the measured floor RL and explicit offsets. |
| Image opacity must be between 0 and 1 | The saved opacity is outside 0–1. | Use the opacity slider or restore a value from 0 to 1 in valid metadata. |
| Image visibility must be true or false | The saved visibility is not a Boolean. | Use true or false, preferably by saving through the app. |
| Enter finite coordinates and positive image width and length | Size/rotation inputs are invalid. | Enter finite coordinates/rotation and positive width and length. |

## Named grave import and relationships

| Message | Cause | Fix |
| --- | --- | --- |
| Duplicate grave ID | Grave IDs are repeated. | Use unique named grave IDs. |
| Choose an existing grave for the cuts-into relationship | A cutting relationship points to itself or a missing grave. | Choose another existing grave, or None recorded. |
| Grave cutting relationships contain a cycle | The cutting relationships loop back to an earlier grave. | Review the recorded interpretation and remove the cyclic relationship. |
| Choose top or base contour | No contour classification has been chosen. | Choose top or base from the survey interpretation; do not guess a missing classification. |
| The imported contour is empty | The imported list has no vertices. | Supply a populated measured contour. |
| Enter a grave name | The new grave has no name. | Enter a nonblank name before importing. |
| Choose an existing grave | The selected destination no longer exists. | Choose an existing grave or create a new named grave. |

## File access, decoding and dialog messages

| Message or pattern | Cause | Fix |
| --- | --- | --- |
| `Could not read this file: …` / `Could not read CSV: …` | File missing, unreadable or an operating-system read error. | Locate the actual file, check access permissions and retry from a readable local copy. |
| `Missing project path.` | A recent/open request has no path. | Use Open and select the project file; if it persists, report the steps to the team. |
| `Could not import grave outline: …` | Survey read/parser failure; the suffix identifies the cause. | Use the matching survey/contour entry above; file-access or decompression details may vary by platform. |
| `Survey file exceeds 16 MB` | Survey file exceeds the import bound. | Obtain a smaller supported survey containing the needed outline. |
| `Choose an XLSX or ROT survey file` | Unsupported survey extension. | Use the correct file picker for XLSX/ROT; project CSV belongs in Open/Add Skeletons. |
| `This photograph could not be decoded. Choose a valid PNG or JPEG.` | Header accepted but native image decoding failed. | Re-export an intact PNG/JPEG from the original photograph. |
| `This site photograph could not be displayed. Load a valid PNG or JPEG.` | Renderer cannot decode the embedded image. | Replace it with an intact supported photograph and save again. |
| `Choose whether the grave cut is the top or base contour` | LN19 classification is unselected. | Confirm classification from the survey record and select top/base. |
| `Complete all alignment fields with finite numbers.` | An image alignment field is blank or invalid. | Complete every alignment field with a finite number, then apply alignment. |
| JSON parser errors, often after `Row {row}:` | Invalid JSON/CSV escaping in image, grave or camera label metadata. | Restore a known-good app-saved record; exact parser wording varies with the runtime. |

Other operating-system/decompression exceptions use platform-dependent wording.
Keep the full message and the steps/file type when reporting an unresolved problem.
Clicking Cancel in a file picker cancels the operation; it is not an import error.

For the expected CSV structure and landmarks, see the
[client workflow guide](client-user-guide.md#prepare-a-csv). For supported client
survey layouts, see [grave-outline formats](data-formats/grave-outline.md).
